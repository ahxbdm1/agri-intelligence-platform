# 使用说明

作品名称：农智云瞰——面向县域农业的农情大数据分析与病虫害风险挖掘平台
参赛队伍：云穗智擎（山东建筑大学 计算机与人工智能学院）　队长：张衡　指导教师：刘新锋
作品版本：v1.0.0　文档版本：v1.0　编写：张菁怡　审核：刘新锋　日期：2026 年 9 月 8 日

## 一、登录

**评审访问地址：`http://47.105.74.222:3001/login`**（评审期内保持开放；本地部署时为 `http://localhost:3000/login`）。

打开登录页，选择演示角色并登录。县域管理员账号 `admin/admin123` 用于完整演示；农技专家账号 `expert/expert123` 适合展示模型解释和巡检复核；合作社账号 `coop/coop123` 适合展示基层协同。

## 二、农情驾驶舱

驾驶舱展示全县种植面积、高风险地块、今日新增病虫害上报、预测减产风险、AI 识别准确率和预警处理率。评委演示时可重点说明这些指标来自数据库接口，而不是前端静态页面。下方风险趋势、作物结构和乡镇风险排名体现多源数据聚合分析能力。

## 三、地图风险监测

进入地图页后，可按乡镇、作物和风险等级筛选地块。地图使用 polygon 展示模拟县域农田，不同颜色代表风险等级。点击地块可查看作物类型、面积、风险评分、主要风险因子、近期天气和巡检建议。

## 四、病虫害识别

上传作物叶片图片后，系统返回疑似病虫害名称、置信度、严重度、防治建议、是否需要人工复核和模型说明。演示版提供模拟 Grad-CAM 区域，用于说明模型关注疑似病斑位置。若无图片，也可直接点击识别按钮体验 mock 返回。

## 五、产量与风险预测

在预测页选择地块后，系统调用风险评分和产量预测接口，展示当前风险评分、风险等级、主要因子贡献和未来七天产量/风险曲线。页面同时展示 MAE、RMSE、R2 等模型指标，便于答辩时说明模型评估。

## 六、预警中心

预警中心展示预警标题、地块、风险等级、触发原因、处理状态、负责人和操作按钮。可将状态切换为待处理、处理中或已完成，也可一键生成巡检任务，体现预警到处置的业务闭环。

## 七、巡检任务管理

巡检任务页展示任务优先级、地点、描述、负责人、截止时间和状态。任务既可由预警中心生成，也可通过 API 创建。演示时建议选择一个高风险任务，将状态从待处理切换到处理中，再说明后续回访数据会回填模型。

## 八、AI 农技助手

助手不是普通聊天框，而是“RAGFlow 远程知识库 + 本地 TF-IDF 降级”的检索增强问答。示例问题包括“番茄早疫病怎么防治？”、“未来三天高湿天气会增加什么风险？”、“哪些地块应该优先巡检？”。回答会结合当前系统高风险地块和天气提示，显示引用来源、调用模式和耗时；远程异常时会明确显示降级原因。

## 九、数据管理

数据管理页展示农田、天气、传感器、病虫害和产量数据规模，支持 CSV 导入校验和预览。生产环境可将导入数据按 dataset 类型写入对应业务表。

## 十、报告生成

报告页可生成全县或指定乡镇的农情风险日报，内容包含 KPI、风险地块、最新预警、模型研判和处置建议。系统输出 Markdown 与 HTML 文件，适合作为日报、答辩材料和演示视频素材。

## 十一、8分钟演示建议

建议按照“背景痛点、系统总览、驾驶舱、地图监测、图像识别、预测模型、AI 助手与报告、技术架构与创新”顺序演示，避免逐页展开所有细节。重点强调业务闭环、模型可解释和工程可运行。
