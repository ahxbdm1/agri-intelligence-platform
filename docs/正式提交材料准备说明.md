## 三、文件命名

通知规定：`团队名称_学校名称_队长姓名_材料名`。全部材料统一使用该格式，当前已按 `云穗智擎_山东建筑大学_张衡_材料名` 生成。

一条命令完成重命名（在项目根目录执行）：

```powershell
.\scripts\refresh_submission.ps1 -TeamName "云穗智擎" -School "山东建筑大学" -Leader "张衡"
```

构建脚本已内置上述团队信息，不带参数运行也会生成正式文件名。
