### 风险分级结果合理性核对

以最新统计日 2026-08-31 为例，80 个地块中高风险 14 个、中风险 36 个、低风险 30 个。高风险集中在水稻（10 个）与番茄（4 个），与两者易感性系数最高（1.15、1.20）、且 8 月底正处于稻瘟病与纹枯病高发期的农技规律一致；小麦、玉米在该时点无高风险地块，与其非当季、易感性系数较低的事实一致。全年分布上，风险评分在 8—10 月达峰、3—5 月最低，符合高温高湿诱发病害的规律。

## 七、缺陷与边界说明

1. **模型指标边界**：PlantDoc 与 IP102 均为公开数据集，所报指标只代表其官方验证集/测试集，**不得表述为山东本地田间识别准确率**。轻量基线在合成样本上的 1.0 指标仅证明训练—保存—加载—调用链路通畅，不具泛化意义。上线前需补充本地样本并由农技专家复核标注。
2. **数据性质**：县域业务数据为固定种子仿真数据，按鲁西南气候与农技规律建模，不含真实个人信息与经营主体信息。
3. **地图底图**：使用在线瓦片服务，网络受限时底图可能不显示，但地块 polygon、风险着色与业务信息仍正常展示。答辩现场建议准备离线截图或本地底图方案。
4. **阈值时效**：风险分级阈值按 2024-09 至 2026-08 的数据分布标定，年际气候变化后应重新标定；阈值集中为两个常量，重标定成本低。
5. **环境依赖**：直接在 Windows 上运行 PySpark 需要 Hadoop winutils，本项目已通过 Docker 方案规避；若使用全局 Python 解释器运行 pytest，可能因 NumPy/SciPy ABI 不匹配在收集阶段失败，须使用项目 `.venv`。
