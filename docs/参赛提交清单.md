## 六、复现与打包命令

```powershell
# 1) 生成大数据明细层（约 35 秒，固定种子可重复）
.\.venv\Scripts\python.exe scripts\generate_bigdata_layer.py

# 2) 运行 Spark ETL 主链路（Docker 方式，无需本机装 Hadoop）
docker compose -f docker-compose.bigdata.yml run --rm spark-local

# 3) 校验 Spark 产出与参考实现口径一致
.\.venv\Scripts\python.exe batch_jobs\pandas_jobs\ads_reference_job.py
.\.venv\Scripts\python.exe scripts\compare_ads_outputs.py

# 4) 生成业务库演示数据并训练模型
.\.venv\Scripts\python.exe scripts\generate_demo_data.py
.\.venv\Scripts\python.exe scripts\train_models.py

# 5) 重新生成全部提交文档与 PPT（并清理旧版本）
.\scripts\refresh_submission.ps1

# 6) 重新打包源代码
.\scripts\build_source_package.ps1
```

`data/lake/_run_report.json` 记录 Spark 各层行数、清洗剔除量与阶段耗时，可作为答辩举证。
