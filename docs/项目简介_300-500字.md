# 项目简介

**问题背景。** 县域病虫害防控长期依赖农技员经验与逐级人工上报，存在发现滞后、气象与物联网等多源数据各成孤岛、风险研判无量化依据、植保资源按面积平摊四个问题。

**解决方案。** 《农智云瞰》以山东省济宁市鱼台县为示范县域，构建县域农情数据湖：明细层覆盖 24 个月、6 个乡镇、80 个地块、5 类作物，含传感器、气象、踏查与测产四类明细共 159 万条。离线分析以 Apache Spark 为主链路完成四层数仓加工，清洗后保留 158 万条有效明细；用窗口函数计算近 14 日病害压力，形成 58,400 行地块-日特征宽表；再由 Spark SQL 产出乡镇风险排名、巡检优先级与农资调度等应用表。在线系统为 Next.js 与 FastAPI 前后端分离架构，提供驾驶舱、风险地图、病虫害识别、产量预测与预警巡检，支持 Docker 一键部署。

**主要创新点。** 一是把 Spark 四层数仓做成唯一的明细加工路径，明细不入业务库；二是刻意注入并逐表度量脏数据，用 99.49% 的有效率把数据治理变成可核对的事实；三是风险分级阈值由全量数据分位数标定并经汛期校核，而非经验常数；四是输出主导风险因子解释成因，并把结论直接推算到各乡镇的无人机架次、农技员与药剂用量。
